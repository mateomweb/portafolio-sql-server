# Portafolio SQL Server Trainee 🗄️

Hola, soy **Mateo** 👋, estudiante y trainee de bases de datos. En este repositorio reúno los ejercicios de práctica que voy haciendo mientras aprendo SQL Server.

## 🗂️ Ejercicios

| Script | Descripción |
|---|---|
| [SISTEMA DE HOTEL.SQL](SISTEMA%20DE%20HOTEL.SQL) | Tabla de habitaciones con consultas por estado y precio, actualización y eliminación de registros. |
| [SALARIOS EMPRESA.SQL](SALARIOS%20EMPRESA.SQL) | Empleados de una empresa: filtros con condiciones, promedio de salarios por departamento con `GROUP BY` y aumentos con `UPDATE`. |
| [NOTAS COLEGIO.SQL](NOTAS%20COLEGIO.SQL) | Notas de alumnos: promedios por alumno, asignatura y curso, y búsqueda de notas rojas. |
| [SISTEMA DE BIBLIOTECAS.SQL](SISTEMA%20DE%20BIBLIOTECAS.SQL) | Base de datos de biblioteca con usuarios, autores, libros y préstamos. |

## ▶️ Cómo ejecutar

Abre el script en SQL Server Management Studio y ejecútalo completo con **F5**.

## 🛠️ Habilidades practicadas

- `CREATE DATABASE` y `CREATE TABLE`
- `INSERT INTO`
- `SELECT` con `WHERE`, `AND`, `OR` y `ORDER BY`
- Funciones de agregado: `AVG`, `COUNT`, `MAX` y `MIN`
- Agrupar resultados con `GROUP BY`
- `UPDATE` y `DELETE`
